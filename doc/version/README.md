### v0.6.0 额外完成（不在原 P1 清单里）

| 内容 | 为什么需要 |
|---|---|
| 游戏列表页 + 小恐龙游戏 | 用户要求"游戏放在功能列表里，先加谷歌小恐龙" |
| 游戏宿主层（可复用外壳） | 暂停/结算面板、防息屏、闹钟自动暂停对**所有游戏**通用，加第二款游戏只需写一个文件 + 注册一行 |
| 2bpp 索引画布 + 脏带刷新 | 整屏刷新要 27ms（只有 37FPS 上限），只刷下面那条带子才有 30FPS 余量 |
| 精灵提取工具 `gen_dino_sprites.py` | 从参考工程的 2 倍图精确折半出 1x 像素画，手工抄点阵不可能 |
| 难度公平性自检（机器玩家） | 第一版的物理参数**数学上跳不过去**，人肉试玩只会觉得"这游戏好难" |

## 怎么加一个新版本

1. 复制 `v0.3.0.md` 当模板（结构：目标 → 改了什么 → 踩的坑 → 验证结果 → 已知局限 → **改动简单说明**）
2. 文件名用 `vX.Y.Z.md`
3. 更新本文件顶部的版本列表
4. **同步代码里的版本号**（三处，改一处容易漏）：
   - `components/app/app.c` 的 `APP_VERSION_STR`
   - `components/watch_ui_pages/pages/watch_page_settings.c` 的 `WATCH_FIRMWARE_VERSION`
   - 本目录的版本列表

> **每个版本文档的最后一节必须是「本版本改动简单说明」**
> —— 一段话讲清这一版干了什么，方便快速扫。
