### v0.6.1 额外完成（不在原 P1 清单里）

> 主题是"**不加功能，先把地基补牢**"——详见 [v0.6.1.md](v0.6.1.md)。

| 内容 | 为什么需要 |
|---|---|
| 修 WiFi 页定时器 **use-after-free** | 扫描中按返回会留下一个继续写已释放对象的定时器；**去掉修复后模拟器直接段错误** |
| 修 LVGL **"事件回调里删祖先对象"** | 模态返回 / 游戏退出都在按钮回调里删自己的祖先 → 事件循环返回后读已释放内存；模态侧改异步删、游戏侧把收尾推迟出事件派发 |
| 修 WiFi **"失败被误判成用户主动断开"** | 让 v0.5.0 那套"密码错就自动清凭据并重新询问"的补救逻辑真正生效；**这是后来 WiFi 能恢复的关键**（见 v0.6.1 §8.5） |
| 时钟服务加跨任务临界区 | 时间回调跑在采样任务、响铃推进跑在 LVGL 任务，共享状态原本无保护 |
| 编译 `-Og` → **`-O2`** | 零代码改动拿到性能；顺带**暴露并真修**了 3 处隐藏问题（`strncpy` 不补 `\0` 等） |
| **coredump 分区 + 任务看门狗 panic** | 崩溃后 `idf.py coredump-info` 能拿到**出错任务 + 带源码行号的调用栈**（已真机验证） |
| 命令行 **`taskmem`/`stats`/`bt`/`crash`** | `taskmem` 直接给出各任务栈水位（据此确认 `data_hub` 提到 4096 是对的） |
| 功能列表 **5 行一屏放下** | 行高 52→43；顺带让该页"上滑开控制中心"恢复（原来因为要滚动而失效） |
| 息屏后第一下触摸**真正不误触** | 原来只有注释说"吃掉了"、实际没实现（LVGL 在调用读回调前就检查 disabled，事后禁用来不及） |
| 开机背光淡入 | 界面就绪后再淡入，不刺眼、不露半成品界面 |

## 怎么加一个新版本

1. 复制 `v0.3.0.md` 当模板（结构：目标 → 改了什么 → 踩的坑 → 验证结果 → 已知局限 → **改动简单说明**）
2. 文件名用 `vX.Y.Z.md`
3. 更新本文件顶部的版本列表
4. **同步代码里的版本号**（**四处**，改一处容易漏 —— 第 4 处是 v0.7.1 才发现的）：
   - `components/app/app.c` 的 `APP_VERSION_STR`（启动 banner + 开发人员→系统信息页）
   - `components/watch_ui_pages/pages/watch_page_settings.c` 的 `WATCH_FIRMWARE_VERSION`
   - **`components/weather/weather_service.c` 的 HTTP `User-Agent` 里的版本号**（服务器端日志能看到是哪版在抓）
   - 本目录的版本列表

   > 自检小技巧：编完之后用
   > `python -c "import sys;t=open('build/smartwatch.bin','rb').read().decode('latin1');print({v:t.count(v) for v in ['0.7.0','0.7.1']})"`
   > 看一眼**旧版本号在镜像里是否已经归零**（注释里的版本号不会进镜像，所以归零才算真的改全）。

> **每个版本文档的最后一节必须是「本版本改动简单说明」**
> —— 一段话讲清这一版干了什么，方便快速扫。
