## 怎么加一个新版本

1. 复制 `v0.3.0.md` 当模板（结构：目标 → 改了什么 → 踩的坑 → 验证结果 → 已知局限 → **改动简单说明**）
2. 文件名用 `vX.Y.Z.md`
3. 更新本文件顶部的版本列表
4. **同步代码里的版本号**（三处，改一处容易漏）：
   - `components/app/app.c` 的 `APP_VERSION_STR`
   - `components/watch_ui_pages/pages/watch_page_settings.c` 的 `WATCH_FIRMWARE_VERSION`
   - 本目录的版本列表

> **每个版本文档的最后一节必须是「本版本改动简单说明」**
> —— 一段话讲清这一版干了什么，方便快速扫。
