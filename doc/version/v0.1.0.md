# v0.1.0 — 硬件点亮

> 日期：2026-10-06（补记）
> 状态：**已被 v0.2.0 取代**，代码结构不再保留
> 性质：验证性版本 —— 目标是"证明硬件是好的"，不是"能继续开发"

---

## 一、目标

从零建起 ESP-IDF 工程，把 Waveshare ESP32-S3-Touch-LCD-1.69 的三条硬件链路跑通：
屏幕能亮、触摸有反应、LVGL 能跑。

## 二、改了什么

### 1. 工程骨架

- 建 ESP-IDF 工程（`firmware/smartwatch/`），目标 `esp32s3`
- 分区表：4MB app + 11MB storage（16MB Flash）
- 配置：QIO 80MHz Flash、8MB Octal PSRAM 80MHz、CPU 240MHz

### 2. 硬件驱动（全部写在 `components/bsp/bsp.c` 一个文件里）

| 器件 | 接口 | 关键点 |
|---|---|---|
| ST7789V2（240×280） | SPI2，40MHz | 三个关键调用：`mirror(true,true)` + `set_gap(0,20)` + `invert_color(true)`，少一个就花屏/偏色/偏移 |
| CST816T 触摸 | I2C0，0x15 | 用 `esp_lcd_touch_cst816s`，注意 `scl_speed_hz` 厂家宏没初始化 |
| 背光 | LEDC PWM，GPIO15 | TIMER_0 / CHANNEL_0 |

### 3. LVGL 集成

- LVGL 8.4.0 + `esp_lvgl_port`（LVGL 跑在独立 FreeRTOS 任务里）
- 双缓冲，`buffer_size = 240×80`
- 触摸输入设备注册时设了手势参数（`gesture_limit` / `gesture_min_velocity`）

### 4. 界面（全写在 `main/main.c`，260 行）

- 4 个页面：表盘 / 健康 / 运动 / 设置
- 表盘：大号时间 + 日期 + 星期 + 三张指标卡（STEPS / BPM / BATT）
- 页面切换：**点屏幕左半边返回、右半边前进**
- 所有数据都是写死的演示值

## 三、这一版验证到了什么

- ✅ 屏幕点亮，LVGL 界面正常显示
- ✅ 触摸响应，点击能切页
- ✅ 串口有启动日志，无报错
- ✅ 工程能编译（`smartwatch.bin` 636KB）能烧录

## 四、遗留问题（v0.2.0 要解决的）

| # | 问题 | 影响 |
|---|---|---|
| 1 | 界面代码全堆在 `main.c` | 加一个功能就要动它；想复用界面只能复制粘贴 |
| 2 | 时间/电量都是假数据 | 还不是"能看时间的手表" |
| 3 | 没有中文字库 | 界面只能全英文 |
| 4 | 切换页用"点半边屏" | 像开发板，不像手表 |
| 5 | 组件从网上下载 | 换电脑要联网；且组件管理器在 IDF 5.5 上有死循环问题 |
| 6 | 共享 I2C 总线由 BSP 持有 | RTC/IMU 驱动要读寄存器就得反向依赖 BSP，依赖方向不对 |

## 五、这一版踩的坑

（当时没有记录，后来在 v0.2.0 的架构文档里统一整理了，见
`../../../../doc/代码架构说明.md` 第六章）

主要是三个环境类问题：

| # | 坑 | 症状 |
|---|---|---|
| 1 | 中文路径 | CMake 报 `FileNotFoundError`，路径变乱码 |
| 2 | `sdkconfig.defaults` 里写中文注释 | `Missing required kconfig option after retry` |
| 3 | Python 环境版本不匹配 | `export.ps1` 找不到 py3.12 环境 |
| 4 | 组件管理器解析 Kconfig 死循环 | `Missing required kconfig option after retry`（重试 3 次放弃） |

> 坑 4 的解决办法是**把组件本地化**：把 `managed_components/` 里的四个组件
> 移到 `components/` 并去掉前缀，然后 `IDF_COMPONENT_MANAGER=0`。
> 附带好处是工程变自包含。

## 六、本版本改动简单说明

> **第一次把板子点亮：屏幕、触摸、LVGL 三条链路跑通，写了 4 个页面的演示界面。**
>
> 这一版的价值是**证明硬件没问题**；代价是代码全堆在 `main.c` 里，
> 时间/电量是假的，界面全英文。
> 这些遗留问题就是 v0.2.0 要解决的全部内容。
