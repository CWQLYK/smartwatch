### 坑 1：中文路径会让 ESP-IDF 编译失败 ❌

**现象**：CMake 报错 `FileNotFoundError`，路径里的中文变成乱码：

```
D:/my/DanPianJi/Project/�����ֱ�/firmware/smartwatch/build/kconfigs.in  ← 找不到
                         ↑ 智能手表 变乱码
```

**原因**：ESP-IDF 的 CMake + Python 工具链在 Windows 上对非 ASCII 路径支持不好。

**解决方案（二选一）**：

| 方案 | 做法 | 推荐度 |
|---|---|---|
| **A. 工程放纯英文路径** | 比如 `D:\my\esp\smartwatch\` | ⭐⭐⭐ **最省事** |
| **B. 设置 UTF-8 环境变量** | 见下方代码 | ⭐⭐ 有效但需每次设置 |

**方案 A（推荐）**：
```
D:\my\esp\smartwatch\        ← 工程放这里（纯英文）
D:\my\DanPianJi\Project\智能手表\doc\   ← 文档和资料留在这里
```

**方案 B**：在每次编译前设置
```powershell
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
```
> 实测方案 B 能解决**路径**问题（中文路径能正常识别了）。

### 坑 2：`sdkconfig.defaults` 里不能写中文注释 ❌

**现象**：
```
C:\Users\...\kconfgen_tmpvh07q75_:1 line was updated to # ==================== 目标芯片 ====================n
Missing required kconfig option after retry.
cmake failed with exit code 1
```

**原因**：kconfgen 解析 `sdkconfig.defaults` 时，中文注释会破坏解析，导致关键配置项丢失。

**解决**：**`sdkconfig.defaults` 用纯英文注释**（代码文件里写中文注释没问题，只有这个配置文件不行）。

### 坑 3：Python 环境版本不匹配 ⚠️

**现象**：直接用 `export.ps1` 激活时报错：
```
ERROR: ESP-IDF Python virtual environment "...\idf5.5_py3.12_env\Scripts\python.exe" not found
```

**原因**：`export.ps1` 按**系统 Python 版本**（3.12）去找虚拟环境，但安装器创建的是 **3.11** 环境。

**解决**：**不要用 `export.ps1`，用 `Initialize-Idf.ps1`** 并指定 IdfId（见下节）。

### 坑 4：组件管理器在 ESP-IDF 5.5 上解析 Kconfig 失败（最坑的一个）

**现象**：CMake 反复重试 3 次后放弃：

```
CMake Warning: Missing kconfig option.  Re-run the build process...
WARNING: The following Kconfig variables were used in "if" clauses, but not
found in any Kconfig file:
    LV_USE_LIBJPEG_TURBO, introduced by espressif/libjpeg-turbo, defined in (unknown)
    LV_USE_LIBPNG, introduced by espressif/libpng, defined in (unknown)
    LV_USE_LZ4, introduced by espressif/lz4, defined in (unknown)
CMake Error: Missing required kconfig option after retry.
```

**根因**（翻 ESP-IDF 源码定位到的）：

| 位置 | 内容 |
|---|---|
| `project.cmake:764-768` | `idf_build_process` 返回 **10** 就重试一次，再返回 10 就报致命错误 |
| `build.cmake:591` | `set(__RERUN_EXITCODE 10) # missing kconfig` |
| `build.cmake:614-633` | 组件管理器 `prepare_components` 返回 10 = 缺少 Kconfig 选项 |

**为什么死循环**：组件市场服务端给 `lvgl` 声明的**可选依赖**（libpng / libjpeg-turbo / lz4）带了 `if LV_USE_LIBPNG` 这类条件，而这些 Kconfig 符号来自**还没安装的组件** → 组件管理器永远要重跑 → 死循环。

**反复试过、都没用的方案**（别再浪费时间）：

| 尝试 | 结果 |
|---|---|
| 重跑 `idf.py build` | 一样失败 |
| 清空 `managed_components` + `dependencies.lock` | 一样失败 |
| 降 LVGL 到 8.3.11 | 一样失败 |
| 降 esp_lvgl_port 到 2.3.3 | 一样失败 |
| 最小化 `sdkconfig.defaults` | 一样失败 |

**有效方案：绕过组件管理器，把组件本地化**

```
1) 把 managed_components/ 里的组件移到 components/（去掉前缀重命名）
     lvgl__lvgl                       -> components/lvgl
     espressif__esp_lvgl_port         -> components/esp_lvgl_port
     espressif__esp_lcd_touch         -> components/esp_lcd_touch
     espressif__esp_lcd_touch_cst816s -> components/esp_lcd_touch_cst816s
2) 删掉 managed_components/ 和 dependencies.lock
3) main/idf_component.yml 只留 idf 依赖
4) 编译时设置 $env:IDF_COMPONENT_MANAGER = "0"
```

**附带好处**：工程变**自包含**，换电脑不用联网下载组件。

### 坑 5：esp_lvgl_port 会猜错 LVGL 版本

**现象**：编译 `esp_lvgl_port/src/lvgl9/...` 时一堆错：

```
error: implicit declaration of function 'lv_draw_buf_width_to_stride'
error: passing argument 1 of 'lv_disp_flush_ready' from incompatible pointer type
```

**根因**：`esp_lvgl_port/CMakeLists.txt` 第 17-28 行取版本号的逻辑：

- 如果 `lvgl` 是**本地组件** → 从**环境变量 `LVGL_VERSION`** 取
- 如果是组件管理器下载的（`lvgl__lvgl`）→ 从组件属性取
- **取不到就默认按 LVGL 9 编译**

组件本地化后走第一个分支，`LVGL_VERSION` 为空 → 编译了 lvgl9 源码 → 全错。

**解决**：编译时设置

```powershell
$env:LVGL_VERSION = "8.4.0"
```

### 坑 6：LVGL 8 的类型名是 lv_disp_t，不是 lv_display_t

**现象**：

```
error: unknown type name 'lv_display_t'; did you mean 'lv_disp_t'?
```

**根因**：`lv_display_t` 是 **LVGL 9** 引入的名字，LVGL 8.x 里叫 **`lv_disp_t`**。

`esp_lvgl_port` 的头文件用了新名字，但它在 LVGL 8 分支下会**自动 include `esp_lvgl_port_compatibility.h`** 做兼容：

```c
#if LVGL_VERSION_MAJOR == 8
#include "esp_lvgl_port_compatibility.h"
#endif
```

**你自己的 BSP 头文件**不走这个兼容层，就得用 LVGL 8 的原生名字。

**解决**：BSP 里统一用 `lv_disp_t`

```c
/* bsp.h */
lv_disp_t *bsp_display_get(void);   /* 不要写 lv_display_t */
```

## 三、板级驱动（BSP）

### 3.1 硬件参数（从原理图 V2.1 逐个核对）

#### 屏幕 — ST7789V2（4 线 SPI）

| 项 | 值 | 说明 |
|---|---|---|
| 分辨率 | **240 × 280** | 注意不是常见的 240×320 |
| 接口 | SPI2_HOST | |
| 像素时钟 | 40 MHz | |
| 色深 | 16 bit（RGB565） | |
| SCLK | **GPIO6** | |
| MOSI | **GPIO7** | MISO 不用（只写） |
| RST | **GPIO8** | |
| DC | **GPIO4** | |
| CS | **GPIO5** | |
| BL | **GPIO15** | 背光，可 PWM 调亮度 |

**⚠️ 三个关键初始化调用，少一个屏幕就不正常**：

```c
esp_lcd_panel_reset(panel);
esp_lcd_panel_init(panel);
esp_lcd_panel_mirror(panel, true, true);        // ← 屏幕是镜像安装的
esp_lcd_panel_set_gap(panel, 0, 20);            // ← ST7789 是 240x320 控制器，
                                                 //    可见区 280，Y 偏移 20
esp_lcd_panel_invert_color(panel, true);        // ← 颜色反转，不加颜色是反的
esp_lcd_panel_disp_on_off(panel, true);
```

#### 触摸 — CST816T（I2C）

| 项 | 值 |
|---|---|
| I2C 地址 | **0x15** |
| I2C 端口 | I2C_NUM_0 |
| SCL | **GPIO10**（和 IMU/RTC 共享） |
| SDA | **GPIO11**（共享） |
| RST | **GPIO13** |
| INT | **GPIO14** |
| 速度 | 400 kHz |

> ⚠️ **I2C 总线是共享的**：触摸(0x15) + IMU(0x6B) + RTC(0x51) 都挂在 GPIO10/11 上，
> 初始化时**只能安装一次 I2C 驱动**，别的模块直接用这个总线。

#### 背光 — PWM 调亮度

```c
// 用 LEDC 产生 PWM，而不是单纯的 GPIO 高低电平
ledc_timer_config_t tcfg = {
    .speed_mode      = LEDC_LOW_SPEED_MODE,
    .timer_num       = LEDC_TIMER_0,
    .duty_resolution = LEDC_TIMER_10_BIT,   // 0-1023
    .freq_hz         = 5000,
    .clk_cfg         = LEDC_AUTO_CLK,
};
ledc_timer_config(&tcfg);

ledc_channel_config_t ccfg = {
    .gpio_num   = GPIO_NUM_15,   // LCD_BL
    .speed_mode = LEDC_LOW_SPEED_MODE,
    .channel    = LEDC_CHANNEL_0,
    .timer_sel  = LEDC_TIMER_0,
    .duty       = 1023,
    .hpoint     = 0,
};
ledc_channel_config(&ccfg);

// 设 50% 亮度：ledc_set_duty(..., 511); ledc_update_duty(...);
```

### 3.2 BSP 组件（`components/bsp/`）

**设计目的**：把硬件初始化封起来，主程序只管业务逻辑。

#### `components/bsp/include/bsp.h`

对外接口：

```c
esp_err_t     bsp_init(void);            // 初始化整块板子
lv_display_t *bsp_display_get(void);     // 拿 LVGL 显示对象
lv_indev_t   *bsp_touch_get(void);       // 拿触摸输入设备
esp_err_t     bsp_backlight_set(int percent);  // 0-100
int           bsp_backlight_get(void);
bool          bsp_display_lock(uint32_t timeout_ms);  // ★ 操作 UI 前必须加锁
void          bsp_display_unlock(void);
```

引脚宏定义也放这里，方便以后改板子。

#### `components/bsp/CMakeLists.txt`

```cmake
idf_component_register(
    SRCS "bsp.c"
    INCLUDE_DIRS "include"
    REQUIRES esp_lcd esp_driver_gpio esp_driver_spi esp_driver_i2c esp_driver_ledc
    PRIV_REQUIRES esp_lvgl_port esp_lcd_touch_cst816s
)
```

### 3.3 ⭐ 多任务注意：LVGL 必须加锁

`esp_lvgl_port` 在**独立任务**里跑 LVGL。任何其他任务要碰 UI，都必须：

```c
if (bsp_display_lock(0)) {
    lv_label_set_text(lbl, "hello");
    bsp_display_unlock();
}
```

**不加锁会出现随机崩溃或画面撕裂。**

```
components/rtc/
```

对外 API 建议：
```c
esp_err_t rtc_init(void);
```

#### 验证

### M3：电量显示 + 多页面

|---|---|
| 引脚 | **GPIO1**（BAT_ADC） |
| 分压 | **R3=200K / R7=100K**，分压比 **1/3** |
| ADC | ADC1_CH0 |

**电压换算**：
```
ADC 读到的电压 × 3  = 电池电压
锂电池范围：3.0V(空) ~ 4.2V(满)
电量百分比 ≈ (V - 3.0) / (4.2 - 3.0) × 100%
```

> ⚠️ 用 `adc_cali` 做校准，否则读数不准。ESP32-S3 支持硬件校准。

#### 验证

- [ ] 串口打印电池电压，和万用表量的对比（误差 < 0.1V）
- [ ] 插 USB 充电时电压上升

### M4：计步（IMU）

#### 硬件

| 项 | 值 |
|---|---|
| 芯片 | **QMI8658C**（6 轴：3 轴加速度 + 3 轴陀螺） |
| I2C 地址 | **0x6B** |
| INT2 | GPIO38 |

#### 实现步骤

| # | 步骤 |
|---|---|
| 1 | 复用共享 I2C 总线，初始化 QMI8658C |
| 2 | 配置加速度计量程 ±4g，输出速率 50Hz |
| 3 | 读三轴加速度，算合矢量模长 |
| 4 | 做低通滤波，去掉重力分量 |
| 5 | 峰值检测算法计步 |
| 6 | 加防抖：步间隔 < 250ms 不计 |

**简单计步算法思路**：

```
1. 算合加速度模长 |a| = sqrt(ax² + ay² + az²)
2. |a| 减去 1g 得到动态分量 d
3. d 过一个带通滤波器（0.5-3 Hz）
4. 检测波峰：d 超过阈值(如 0.15g) 记为一个可能的步
5. 两次峰值间隔 > 250ms 才算有效步
```

#### 验证

- [ ] 拿在手上正常走 100 步，误差 < 10 步
- [ ] 静止放桌上 10 分钟，步数不涨
- [ ] 快速摇晃，不会疯狂误计

### M6：中文字体

**LVGL 自带字体不含中文**，需要自己生成。

#### 生成方法（PC 上已验证可行）

```powershell
# 用 lv_font_conv 从 Windows 字体生成
npx lv_font_conv --font "C:\Windows\Fonts\simhei.ttf" \
  --size 16 --bpp 4 --no-compress --format lvgl \
  -o main/lv_font_simhei_16.c \
  --range 0x20-0x7F \
  -r 0x65F6 -r 0x95F4 -r 0x65E5 -r 0x671F ...   # 用到的字的码点
```

> ⚠️ **必须加 `--no-compress`**！LVGL 8.x 读不了压缩位图，症状是**字形能查到但显示成豆腐块**。

| 心 | 0x5FC3 | 率 | 0x7387 |

### M7：BLE 连接手机

#### 目标

| 功能 | 说明 |
|---|---|
| 设备广播 | 手机蓝牙能搜到 |
| 连接 | 能连上 |
| 时间同步 | 手机下发时间，手表更新 RTC |
| 电量上报 | 手表上报电量 |

#### 实现

用 ESP-IDF 的 **NimBLE** 协议栈（比 Bluedroid 省内存）。

自定义 GATT 服务：
```
Service UUID:  自定义
├── Char: 当前时间  (Write)   ← 手机写入时间
├── Char: 电量      (Read/Notify)
├── Char: 步数      (Read/Notify)
└── Char: 心率      (Read/Notify)  ← 留给 P4
```

#### 验证

- [ ] 用手机 nRF Connect 能搜到设备
- [ ] 能连接并看到服务
- [ ] 写入时间后，手表时间变了

## 六、故障排查

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | `FileNotFoundError` + 路径乱码 | **中文路径** | 工程移到英文路径，或设 `PYTHONUTF8=1` |
| 2 | `Missing required kconfig option` | **sdkconfig.defaults 有中文注释** | 改成纯英文注释 |
| 3 | `Python virtual environment not found` | 用了 `export.ps1` | 改用 `Initialize-Idf.ps1 -IdfId ...` |
| 4 | 组件下载失败 | 网络 | 见下方 6.1 |
| 5 | 屏幕全黑 | 背光没开 / 初始化顺序 | 检查背光 GPIO15 是否拉高 |
| 6 | 屏幕花屏 | 缺 `set_gap` 或 `invert_color` | 补上三个关键调用 |
| 7 | 屏幕显示偏移 | `mirror` 或 `gap` 参数不对 | 试 `set_gap(0, 20)` |
| 8 | 颜色反了 | 缺 `invert_color(true)` | 补上 |
| 9 | 触摸位置不准 | 坐标轴映射 | 调 `swap_xy` / `mirror_x` / `mirror_y` |
| 10 | 随机崩溃 | 没加 LVGL 锁 | 碰 UI 前 `bsp_display_lock()` |
| 11 | 中文显示成豆腐块 | 字体压缩 / 缺字形 | 用 `--no-compress` 重新生成字体 |
| 12 | 编译很慢 | 正常 | 首次 2-5 分钟，之后增量几秒 |

### 6.1 组件下载失败的解决

**方案 A：设置国内镜像**
```powershell
$env:IDF_COMPONENT_REGISTRY_URL = "https://components-file.espressif.cn"
```

**方案 B：手动放到本地**
```
从 https://components.espressif.com 下载组件包，
解压后放进工程的 components/ 目录，删掉 idf_component.yml 里对应的依赖行。
```
